## 2026-09-18 — design decision

The estate declaration is a non-secret overlay, not a second complete copy of the relay
contract. `from_address` is required when an enabled estate mail block is present;
`from_name`, `provider`, `host`, `port`, `encryption`, and `username` are optional
non-secret overrides. The resolver strips the global password, applies the estate's
non-secret block, and assigns the result as a whole `mail` key. This preserves one
shared relay credential for the normal case while preventing a recursive fact merge from
leaving the default estate's From identity in place.

An optional `homelab-infra/estates/<estate>/mail` item carries only `password`. It is a
separate escape hatch for relays that require per-domain logins; the selected estate's
item wins, no other estate item is considered, and an absent item falls back to the
shared global `homelab-infra/mail` credential. Store Secret is the post-cutover path for
that item. No mail topology is generated by `write-generated-facts.yml`, so no generated
mail fact is introduced.
